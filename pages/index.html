핵심 기능

RPA 상영 시간표 동기화

Playwright Headless Chromium으로 WAF가 적용된 CGV까지 수집, 메가박스·롯데시네마는 JSON 엔드포인트 수집. 실패 시 모의 데이터 자동 폴백.

명당 자리 자동 하이라이트

스크린 대비 2/3 지점·중앙 열 기반 NumPy 점수 모델로 상위 18% 좌석을 명당으로 표시하고 히트맵 제공.

실시간 잔여석 알림

좌석 모니터가 취소표를 감지하면 WebSocket 팝업·토스트·브라우저 알림 및 텔레그램/디스코드/이메일 웹훅 송출.

관리자 콘솔

크롤링 주기·성공/실패 로그·Plotly 성능 리포트 모니터링, 회원 권한(일반 ⇄ 관리자) 실시간 변경.
